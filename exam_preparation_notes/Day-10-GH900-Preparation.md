## Incorrect Q18 — Merge Strategy
You answered:
```text
Rebase and merge
```

Correct:
```text
Merge commit
```

Why:
The question required:
```text
preserve individual commits
AND
show explicit merge point
```

Memory shortcut:
```text
One clean commit → Squash
Linear history → Rebase
Visible merge point → Merge commit
```

## Incorrect Q25 — Project View
You answered:
```text
Roadmap
```

Correct:
```text
Board
```

Scenario:
```text
Todo → In Progress → Review → Done
```

That is a workflow/status problem.

Shortcut:
```text
Board = where is work in workflow?
Roadmap = when is work happening?
Table = what structured data?
```
