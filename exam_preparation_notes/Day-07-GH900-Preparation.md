## GitHub Community & Open Source

**Goal:** Understand open source, Sponsors, Marketplace, following, forks/templates, discoverability, and InnerSource.

## Open Source
Benefits:
- transparency
- community contribution
- shared maintenance
- learning/reuse
- broader testing
- innovation

Important:
```text
Public repository ≠ automatically open source
```
The `LICENSE` defines legal reuse/modification/distribution rights.

### Contribution forms
Not just code:
- bug reports
- issue triage
- docs
- testing
- design
- reviews
- mentoring
- support

### Typical open-source workflow
```text
Original repo
→ Fork
→ Clone
→ Branch
→ Change
→ Push
→ Pull Request
```

---

## GitHub Sponsors
Financial support for open-source contributors/organizations.

## Following users/organizations
Stay informed about account activity.

Distinguish:
```text
Star = bookmark repo
Watch = repo notifications
Follow = user/org activity
```

## GitHub Marketplace
Discover GitHub-compatible tools/integrations.

Marketplace ≠ workflow engine. Actions is the automation platform.

---

## InnerSource
Open-source development practices inside an organization.

Example:
```text
Internal reusable framework
→ discover
→ open Issues
→ contribute via PRs
→ review
→ reuse across teams
```

### Discoverable repositories
Helpful metadata:
- clear name
- description
- README
- topics
- docs
- ownership/contact info

### Fork vs Template
- Fork = related copy, often for contribution.
- Template = new independent repo from starter content.

### Community standards
- README
- LICENSE
- CONTRIBUTING
- CODE_OF_CONDUCT
- SECURITY
- Issue/PR templates
