# Day 8 - End-to-End GitHub Workflow

## GitHub Flow

Issue
→ Branch
→ Changes
→ Commit
→ Push
→ Pull Request
→ Review
→ Checks
→ Merge

## Key Concepts

- Issue tracks work
- Branch isolates development
- Commit records changes
- Push sends commits to GitHub
- Pull Request proposes changes
- GitHub Actions can validate changes
- Merge integrates approved work
